Talkify

Language: Python

Talkify is a Python-based Telegram bot created as a replacement for the Datingify bot, which had been under maintenance for an extended period.

The project was discontinued due to funding issues and the return of the Datingify bot.

However, this does not rule out the possibility of Talkify returning in the future.

NovaStream

Language: HTML, JavaScript

NovaStream is a website project for watching football matches for free, funded by the community.

The website uses stream sources from Sportsrc for its video player.

The project was discontinued due to a lack of funding and the expiration of the domain used for the website.

NovaStream will return in the future under a different domain name.

RamaSRC

Language: HTML, JavaScript

RamaSRC is a website project for watching football matches for free.

This website is using V2 of SportSRC V2 which is paid (free plan limited 1000 data).

The project was continued but not announced publicly like NovaStream before, only for personal entertainment purpose :p

Domain: ramaram.my.id/stream

project-heiakim

Language: Python, Java

project-heiakim is a project consisting of three main parts: a discord moderation bot, a discord music bot, and a minecraft java server used by the "heiakim #alterpop" discord server.

The minecraft server runs on minecraft java v.26.2 with several plugins, including floodgate, spark, and other supporting plugins. The server also uses geyser to allow minecraft bedrock (pocket edition) players to play on the same server as java edition players (crossplay).

The discord bots are custom-built bots with features for welcoming new members, basic moderation, and music queuing.

project-heiakim is hosted through termux on an old phone, running without any hosting costs.

Economy system for activity, work command, daily, shop, inventory, profile and so much more <3.
